# India_workforce_intelligence



An AI-powered research platform that identifies,
extracts, and classifies workforce management
problems across Indian industries using publicly
available information.

## Objectives

- Identify workforce challenges across industries.
- Analyse public reports, datasets and research.
- Classify problems into standard HR categories.
- Maintain an evidence-backed research database.
- Generate Excel reports and interactive dashboards.

## Technology Stack

- Python
- Google Colab
- OpenAI API
- Streamlit
- Supabase
- GitHub

Development in progress.
