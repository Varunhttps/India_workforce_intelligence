# Weekly Signal Momentum

Compares the number of distinct supporting sources for each industry/workforce-problem grouping across the current ISO week and previous ISO week, based on the research history's **Weeks Seen** metadata.

## Dashboard outputs
- Evidence/source count by week, delta and direction label.
- Country breadth for context.
- Ranked industries by current source breadth, problem diversity and increasing evidence.
- Candidate tags for staffing and planning opportunities, based on problem-type keywords.

## Interpretation guardrails
Counts reflect public research coverage and publication/discovery signals—not workforce problem severity or verified market demand. A decrease or a problem not observed in a scan is not evidence that the problem is resolved. Keyword opportunity tags are screening hints, not commitments.

The dashboard derives records from the cumulative findings history and does not require an additional external API call.
